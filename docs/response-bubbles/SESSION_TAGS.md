# Response Bubbles — Session tags (normative)

> **Status:** Frozen v1 (Response Bubbles project)  
> **Canonical contract:** [BUBBLE_CONTRACT.md](https://github.com/nodus-factory/nodus-llibreta-v2/blob/feature/response-bubbles-nostr-async/docs/BUBBLE_CONTRACT.md) (Llibreta; read-only reference)

The `bubble` tag correlates every DW response event to a single **response bubble** (one user question or system task). The bubble ID is a UUID v4.

---

## Required tags — DW → human (kinds 10002, 10003, 10006, 10007, 10008, 10009)

| Tag | Value | Notes |
|-----|-------|-------|
| `p` | Recipient pubkey (hex) | Indexed on the relay |
| `session` | Page session string | Same semantics as today (e.g. `page_{notebookId}_{pageNumber}`) |
| `request` | Invocation UUID | One per DW invocation; may repeat after HITL resume |
| `bubble` | Bubble UUID v4 | **MUST** match the `bubble` on the originating kind:10001 |

Publishers **MUST** copy `bubble` from the inbound kind:10001 and **MUST NOT** mint a new bubble ID for the same user turn.

---

## Required tags — Llibreta → DW (kind 10001)

| Tag | Value |
|-----|-------|
| `p` | Target DW pubkey (hex) |
| `session` | Page session string |
| `request` | New UUID per invocation |
| `bubble` | UUID v4 **generated by Llibreta before publish** |
| `client` | `llibreta-server-bridge` |

Optional tags unchanged: `token`, `page`, `context`.

---

## Recommended optional tags

| Tag | Values | Use |
|-----|--------|-----|
| `page` | `{notebookId}:{pageNumber}` | Routing when `session` is insufficient |
| `phase` | `ack` \| `partial` \| `final` \| `error` | Delivery semantics |
| `event` | See [KINDS.md](./KINDS.md) § logical types | Logical type when not using kind:10007 |
| `worker` | npub hex or agent id | Multi-DW inside one bubble |
| `seq` | integer | Stable ordering when needed |
| `bubble_done` | `true` | **Legacy only** on kind:10002 — closes bubble if no kind:10009 |

---

## INBOX (kinds 10020, 10021)

- kind:10020 **MUST** include `bubble` when the inbox action belongs to an in-flight response.
- kind:10021 resolution semantics are unchanged; Llibreta projects updates onto the bubble.

---

## Relay indexing

Relays **SHOULD** index `bubble` (and `session`, `request`) in `indexedTags` so subscribers can filter with `#bubble` and `#session` without full-table scans. See [nodus-adk-infra STRFRY relay docs](https://github.com/nodus-factory/nodus-adk-infra/blob/feature/response-bubbles-nostr-async/docs/response-bubbles/STRFRY_RELAY.md).

---

## Closure semantics (frozen)

| Mechanism | Closes bubble? |
|-----------|----------------|
| kind:10009 `BUBBLE_FINAL` | **Yes** (canonical) |
| kind:10002 + tag `bubble_done=true` | Yes (compatibility only) |
| kind:10002 without `bubble_done` and no prior 10009 | No (append message) |
| kind:10006 | No |
| kind:10003 | Sets bubble to `waiting` (HITL) |
